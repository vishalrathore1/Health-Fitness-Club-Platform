
# Health & Fitness Club Membership Platform

## Project Overview
A data-driven Health & Fitness Club Membership Platform developed using MySQL and Microsoft Power BI to analyze gym membership, revenue, payment methods, and attendance.

## Tools & Technologies
- MySQL – Database management and SQL analysis
- Microsoft Power BI – Interactive dashboard and visualization
- PowerPoint – Project presentation

## Key Features
- Member and membership plan analysis
- Revenue and Monthly Recurring Revenue (MRR) analysis
- Payment method analysis
- Attendance analysis
- Membership performance dashboard

## Project Files
- SQL Script – Database queries and data preparation
- Power BI Dashboard – Interactive analytical dashboard
- Project Presentation – Project overview and findings
- Project Report – Detailed project documentation
- Dashboard Screenshots – Visual representation of results

## Key Findings
- 1,000 member records in the analytical dataset
- 2 membership plans: Premium and Standard
- ₹3.99M modeled revenue
- Payment method distribution across Card, Cash and UPI

## Data Limitations
The analytical dataset contains demonstrative/synthetic plan assignments and one-day payment and attendance records. It does not represent verified historical gym transactions or support meaningful historical churn analysis.
